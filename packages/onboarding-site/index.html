Multi-namespace notes

        
    
          
  • 
            The relay operator configures TOKIMEKI_NAMESPACE_TOKENS and distributes
            one token per namespace. Hosts use TOKIMEKI_TOKEN +
            TOKIMEKI_NAMESPACE; sessions must be
            <namespace>.<slug>.
          
    • 
          
  • 
            The master-token single-owner fallback and JWT/TokiAPI modes are not covered by this
            page. Ask the relay operator or read docs/deploy-cloudflare.md.
          
    • 
          
  • 
            The generated config file contains the host token. Treat it as a secret:
            chmod 600 tokimeki-config.json, use
            tokimeki --config tokimeki-config.json claude, and delete it when done.
            A browser download is not memory-only.

Security

        
    
          
  • 
            Everything is generated in this browser tab. The page makes no network requests
            (connect-src 'none'), uses no cookies/storage/analytics, and has no
            server-side component.
          
    • 
          
  • 
            Tokens exist only in form fields and generated output. They are never placed in the
            URL, and page JavaScript never logs them. Closing the tab discards them.
          
    • 
          
  • 
            Commands and downloaded files contain secrets. Avoid shell history exposure, do not
            paste them into public channels, and delete the downloaded config after use.
          
    • 
          
  • 
            Commands must be run on an HTTPS-protected page (or localhost) because credentials are
            entered here.
