Notes & security
  • Sessions must be <namespace>.<slug>. The relay operator issues namespace tokens with TOKIMEKI_NAMESPACE_TOKENS; JWT and master-token modes are not covered by this page.
  • Everything runs in this tab: no network requests, cookies, storage, or analytics. Tokens are never logged, and closing the tab discards them.
  • Downloaded configs contain the host token. Treat them as secrets: chmod 600, use tokimeki --config, and delete them when done. Avoid shell history exposure.
  • Commands must be run on an HTTPS-protected page (or localhost) because credentials are entered here.
